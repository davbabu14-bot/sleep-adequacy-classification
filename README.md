# Sleep Adequacy Prediction Using Machine Learning

## Project Overview

This project focuses on predicting whether an individual gets adequate or inadequate sleep using machine learning classification techniques and Python. The objective is to analyse relevant lifestyle and sleep-related factors and classify sleep adequacy based on the available dataset.

## Objective

- Analyse sleep-related and lifestyle data.
- Identify relevant features associated with sleep adequacy.
- Build a machine learning classification model.
- Evaluate the model using suitable classification metrics.
- Predict whether sleep is adequate or inadequate based on input features.

## Problem Statement

Sleep adequacy can be influenced by several factors, including sleep duration, daily habits, and lifestyle patterns. This project uses classification techniques to analyse the available data and predict the sleep adequacy category.

## Dataset

The dataset contains records used to train and evaluate the classification model.

**Target variable:** Sleep adequacy

**Classes:**
- Adequate sleep
- Inadequate sleep
